What should we write next?

We do not publish a roadmap, because the publishing order should come from the people using the library rather than from us. So the question is open: what does your operation need explained that nobody has explained properly?

Send it to info@accountablemail.org. Real questions from real operations set the order, and a question that costs one member time is usually costing twenty others the same. Tell us the service, the form, or the file format you are stuck on, and what you have already tried to find.
